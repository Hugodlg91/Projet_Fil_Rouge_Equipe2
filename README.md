# Projet_Fil_Rouge_Equipe2

🛡️ Projet Fil Rouge - Modernisation Infrastructure CYNA

Ce dépôt contient l'ensemble des scripts d'Infrastructure as Code (IaC), les configurations de sécurité et la documentation technique pour la refonte du Système d'Information de la société Cyna.
Context du Projet

Dans le cadre du déménagement du siège social à Genève et de l'ouverture d'une filiale à Paris, ce projet vise à déployer une nouvelle infrastructure informatique répondant aux enjeux suivants :

Architecture Cloud Hybride : Couplage d'un datacenter On-Premise (Genève) avec le Cloud Public pour la scalabilité.

Sécurité Zero Trust : Segmentation réseau stricte, EDR/XDR généralisé et gestion des accès (IAM) renforcée.

Haute Disponibilité : Continuité de service pour le SOC (24/7) et la plateforme SaaS.

Automatisation DevOps : Déploiement automatisé via Terraform et Ansible pour garantir la résilience (PRA).
